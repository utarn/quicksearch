## 🖥 Examples

- [**Movies**](https://where2watch.quicksearch.com/?utm_campaign=oss&utm_source=github&utm_medium=organization) — An application to help you find streaming platforms to watch movies using [hybrid search](https://www.quicksearch.com/solutions/hybrid-search?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=demos).
- [**Ecommerce**](https://ecommerce.quicksearch.com/?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=demos) — Ecommerce website using disjunctive [facets](https://www.quicksearch.com/docs/learn/fine_tuning_results/faceted_search?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=demos), range and rating filtering, and pagination.
- [**Songs**](https://music.quicksearch.com/?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=demos) — Search through 47 million of songs.
- [**SaaS**](https://saas.quicksearch.com/?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=demos) — Search for contacts, deals, and companies in this [multi-tenant](https://www.quicksearch.com/docs/learn/security/multitenancy_tenant_tokens?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=demos) CRM application.

See the list of all our example apps in our [demos repository](https://github.com/quicksearch/demos).

## ✨ Features
- **Hybrid search:** Combine the best of both [semantic](https://www.quicksearch.com/docs/learn/experimental/vector_search?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features) & full-text search to get the most relevant results
- **Search-as-you-type:** Find & display results in less than 50 milliseconds to provide an intuitive experience
- **[Typo tolerance](https://www.quicksearch.com/docs/learn/relevancy/typo_tolerance_settings?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** get relevant matches even when queries contain typos and misspellings
- **[Filtering](https://www.quicksearch.com/docs/learn/fine_tuning_results/filtering?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features) and [faceted search](https://www.quicksearch.com/docs/learn/fine_tuning_results/faceted_search?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** enhance your users' search experience with custom filters and build a faceted search interface in a few lines of code
- **[Sorting](https://www.quicksearch.com/docs/learn/fine_tuning_results/sorting?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** sort results based on price, date, or pretty much anything else your users need
- **[Synonym support](https://www.quicksearch.com/docs/learn/relevancy/synonyms?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** configure synonyms to include more relevant content in your search results
- **[Geosearch](https://www.quicksearch.com/docs/learn/fine_tuning_results/geosearch?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** filter and sort documents based on geographic data
- **[Extensive language support](https://www.quicksearch.com/docs/learn/what_is_meilisearch/language?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** search datasets in any language, with optimized support for Chinese, Japanese, Hebrew, and languages using the Latin alphabet
- **[Security management](https://www.quicksearch.com/docs/learn/security/master_api_keys?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** control which users can access what data with API keys that allow fine-grained permissions handling
- **[Multi-Tenancy](https://www.quicksearch.com/docs/learn/security/multitenancy_tenant_tokens?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** personalize search results for any number of application tenants
- **Highly Customizable:** customize Quicksearch to your specific needs or use our out-of-the-box and hassle-free presets
- **[RESTful API](https://www.quicksearch.com/docs/reference/api/overview?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=features):** integrate Quicksearch in your technical stack with our plugins and SDKs
- **AI-ready:** works out of the box with [langchain](https://www.quicksearch.com/with/langchain) and the [model context protocol](https://github.com/quicksearch/quicksearch-mcp)
- **Easy to install, deploy, and maintain**

## 📊 Telemetry

Quicksearch collects **anonymized** user data to help us improve our product. You can [deactivate this](https://www.quicksearch.com/docs/learn/what_is_meilisearch/telemetry?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=telemetry#how-to-disable-data-collection) whenever you want.

To request deletion of collected data, please write to us at [privacy@quicksearch.com](mailto:privacy@quicksearch.com). Remember to include your `Instance UID` in the message, as this helps us quickly find and delete your data.

If you want to know more about the kind of data we collect and what we use it for, check the [telemetry section](https://www.quicksearch.com/docs/learn/what_is_meilisearch/telemetry?utm_campaign=oss&utm_source=github&utm_medium=quicksearch&utm_content=telemetry#how-to-disable-data-collection) of our documentation.
